## How It Works

The Payments V2 Test Tools provide the following functions to aid with functional testing:

- Submission of FM36 files for processing in the Earning Events application

- Transmission of messages generated by Data Collections during the Period End process, to allow for testing without full integration

- Transmission of messages generated by Earn and Pay for consumption by the DAS Earnings Bridge

More information here: 
- https://skillsfundingagency.atlassian.net/wiki/spaces/NDL/pages/400130049/4.+Payments+v2+-+Components+DAS+Space

## 🚀 Installation

### Configuration

Create a local file in the `Spike.FM36Tool` project called `local.settings.json` and populate as follows:

```
{
    "Logging": {
        "LogLevel": {
            "Default": "Information",
            "Microsoft": "Warning",
            "Microsoft.Hosting.Lifetime": "Information"
        }
    },
  "AllowedHosts": "*",
  "DcConfiguration": {
    "SubscriptionName": "<name of the Data Collections subscription>",
    "TopicName": "<name of the Data Collections topic>",
    "BlobStorageContainer": "<name of the Blob Storage container>"
  },
  "AppSettings": {
    "ShareName": "<name of the FM36 file share>"
  },
  "ConnectionStrings": {
   "FileStorageConnectionString": "<connection string for the file storage account>",
    "DcStorageConnectionString": "<connection string for the Data Collections storage account>",    
    "DcServiceBusConnectionString": "<connection string for your local DC service bus instance>"
  },
  "DASServiceBusSettings": {
    "ConnectionString": "<connection string for your local DAS service bus instance>",
    "QueueName": "sfa-das-payments-earningsevents-dasearningsbridge"
  }
}
```
